# VirtualBox Configuration

## Purpose

Oracle VirtualBox provides the virtualization platform for the AI Cybersecurity HomeLab.

The virtual environment hosts the systems used for attack simulation, AI processing, and future defensive monitoring.

---

## Current Virtual Machines

- Ubuntu Server
- Kali Linux

---

## Current Status

VERIFIED

The virtualization platform successfully supports the current v0.2.0 milestone, including:

- Ubuntu Server deployment
- Kali Linux deployment
- SSH administration
- Local Ollama inference
- AI-assisted SOC analysis

Additional virtual machines and services will be introduced as the HomeLab expands. These may include centralized logging, defensive monitoring, and security tooling.
